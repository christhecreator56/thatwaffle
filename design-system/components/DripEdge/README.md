Chocolate pouring down the page to carry one scene into the next.

**Provide:** a path element and `TWP.dripPath(width, height, {p, n, seed, base})`, with `p` from 0 to 1.

**Use** between scenes, in the colour of the next scene: `dune` mostly, `umber` into red velvet, `justright` for cream. Use at most 13 drips.

**Don't** stack two drips in a row.
