Headline treatment: fat lowercase Modak letters on a hard offset block.

**Provide:** the text twice, as content and in `data-t`, because the shadow block is drawn from the attribute.

**Use** for one or two lines per scene, 56px or larger, on `umber`, `dune` or `umber-deep`. Swap the block colour with `--sticker`. Each line is its own element so it can tilt on its own.

**Don't** set sentences in it, or use it below 56px.
